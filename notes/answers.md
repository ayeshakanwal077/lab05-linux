The /bin directory is a shortcut to /usr/bin kept so old programs still work.
The /usr/bin directory is where most commands live (like ls, git, python3) installed by Ubuntu.
The /usr/local/bin directory is for programs you add by hand, kept apart from Ubuntu's own.
The sleep command creates a background process. Using ps aux displays current processes, and kill -9 terminates the running task using its PID.
